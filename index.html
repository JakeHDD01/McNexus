Configurações

Serve só para criar a pasta addons/ no repositório quando você aprova um addon. Fica salvo apenas neste aparelho, nunca no código. Crie em GitHub → Settings → Developer settings → Fine-grained tokens, só para esse repositório, com Contents: Read and write.

Adicionar addon

Suba o arquivo (.mcaddon ou .mcpack) no Mediafire, Drive ou GitHub Releases e cole o link aqui.

Depois de salvar, o addon fica “Em análise” até o admin aprovar. Só então a página dele é criada.
